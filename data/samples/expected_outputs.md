# 示例输入输出

## 新岗位

输入 `jobs.jsonl` 并运行岗位分析后，`AI_AGENT_ENGINEER` 应进入候选新岗位列表。岗位画像应包含 AI Agent、RAG、Python、LangChain、MCP、向量数据库等技能，并附原始 JD 来源。

## 既有岗位

`JAVA_DEVELOPER` 的演化对比应显示 Docker、Kubernetes、可观测性或大模型应用相关技能在新时间窗口中出现或提升。每项变化应展示历史占比、当前占比和来源链接。

## 人岗匹配

导入 `resume.txt` 并匹配 Java 开发工程师后，系统应识别 Java、Spring Boot、MySQL、Redis、Docker、Git、Linux 和 CI/CD，输出 Kubernetes 等技能缺口以及按优先级排列的学习路径。
